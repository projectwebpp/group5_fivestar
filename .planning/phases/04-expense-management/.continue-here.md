## Critical Anti-Patterns (do NOT repeat these)

- **NTFS COMPOSER TIMEOUT**: Never run `composer install` on `/mnt/c/` path from WSL — always use native Linux path `/home/teerapong/fivestar_backend/` for PHP test execution. NTFS unzip for large packages times out at 300s.
- **MISSING JWT SECRET**: After copying `.env.example` → `.env`, always run `php artisan key:generate` AND `php artisan jwt:secret --force` before tests — missing JWT secret causes auth()->login() to return null.
- **TYPE-UNSAFE OWNER CHECK**: Always add `$casts = ['user_id' => 'integer']` to models with user_id FK — `$model->user_id !== auth()->id()` fails silently if DB returns string vs integer.
