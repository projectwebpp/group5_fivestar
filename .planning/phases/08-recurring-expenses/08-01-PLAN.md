## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /api/recurring | Unauthenticated input; JWT must be validated before any template access |
| Authenticated user → other user's templates | Horizontal privilege escalation; ownership guard required on every query |
| Request input → Expense::create() via processRecurring() | user_id must come from Auth::id(), never from request or template input |
| category_id in store() → categories table | Cross-user category injection; explicit ownership check required |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Elevation of Privilege | RecurringExpenseController::update(), destroy() | mitigate | `->where('user_id', Auth::id())` on every RecurringExpense query; returns 404 if not found |
| T-08-02 | Tampering | RecurringExpenseController::store() category_id | mitigate | `DB::table('categories')->where('user_id', Auth::id())->exists()` check before create |
| T-08-03 | Tampering | processRecurring() Expense::create() user_id | mitigate | user_id set from Auth::id() argument, never from template input or request body |
| T-08-04 | Denial of Service | processRecurring() flooding GET /api/expenses | mitigate | D-03: at most 1 entry per template per call; `whereDate('start_date', '<=', $today)` excludes future templates |
| T-08-05 | Tampering | processRecurring() mass assignment | mitigate | Expense::$fillable whitelist enforces allowed fields; is_recurring and recurring_id now in $fillable |
| T-08-06 | Spoofing | All /api/recurring routes | mitigate | Routes inside `auth:api` middleware group; 401 returned without valid JWT |
