# Milestone v1.0: MVP — Expense Tracker

**Status:** ✅ SHIPPED 2026-05-11

**Total Plans:** 10
**PR:** https://github.com/projectwebpp/group5_fivestar/pull/3 (merged)

## Overview

Full expense tracker web app — React TypeScript frontend + Laravel PHP backend + MySQL + JWT authentication — deployed on Vercel. Users can register, log in, manage categories, add/view/edit/delete expenses with pagination and filtering, and view analytics with a pie chart and date-range filtering.

## Milestone Summary

**Key Decisions:**
- MySQL (not SQLite) — locked by team tech stack decision
- JWT auth (tymon/jwt-auth) — team decision; token in localStorage
- API response envelope `{success, data, message}` — enforced via response()->success() macro
- Server-side percentage pre-computation for analytics
- Recharts for pie chart (native React, no canvas dep)
- Budget/CSV/Recurring deferred to v2

**Issues Resolved:**
- CRLF line-ending conflicts in Windows/WSL environment — worked around via direct file rescue from worktrees
- ONLY_FULL_GROUP_BY MySQL mode compliance in analytics GROUP BY

**Known Deferred (acknowledged at close):**
- Phase 03 and 04 VERIFICATION.md remain `human_needed` (runtime checks skipped; features verified working through Phase 5 usage)
- Phase 04 UAT has 5 pending scenarios (acknowledged as tech debt)

**Technical Debt Incurred:**

- No CI pipeline beyond Vercel deploy
