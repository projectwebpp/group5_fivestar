Key architectural note for executor: route order is critical. GET /api/expenses/export must be inserted BEFORE GET /api/expenses/{id} in api.php or Laravel will treat the literal "export" as an expense ID and return 404.

The frontend download pattern is: Axios responseType:'blob' → URL.createObjectURL(blob) → programmatic anchor click → URL.revokeObjectURL(). The Axios interceptor in client.ts handles the JWT header automatically — no special auth handling needed on the export function.
