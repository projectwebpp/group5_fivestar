## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff (browser default) | Page background, modal background, card background |
| Secondary (30%) | #f5f5f5 | Category card background; modal overlay backdrop |
| Accent (10%) | #000000 (browser default button) | Primary action buttons (Save, Add Category) |
| Destructive | #dc2626 (red) | Delete confirm button; inline error messages |

Accent reserved for: "Save Category" submit button in modal, "Add Category" trigger button on the page header. Not used on edit/delete icons or navigation links.

**Error text color:** `color: 'red'` — matches AuthPage pattern exactly (`<p style={{ color: 'red' }}>` with `role="alert"`).

**Category card color swatch:** Each card renders a 24×24px filled square using the category's own `color` hex value as `backgroundColor`. This is dynamic per-card, not a design system token.

**Modal overlay backdrop:** `rgba(0, 0, 0, 0.4)` full-screen fixed overlay behind the modal panel.

### 2. Category Card Grid

Layout: CSS grid, `display: 'grid'`, `gridTemplateColumns: 'repeat(auto-fill, minmax(180px, 1fr))'`, `gap: '1rem'`.

Each card:
```
<div style={{ border: '1px solid #e5e5e5', borderRadius: '8px', padding: '1rem', backgroundColor: '#f5f5f5' }}>
  {/* color swatch: 24x24 square, borderRadius: 4px, backgroundColor: category.color */}
  {/* Lucide icon component at size={20} */}
  {/* category name: <strong> */}
  {/* action row: edit icon button + delete/confirm section */}
</div>
```

**Card border-left accent variant (optional):** A 4px left border using `category.color` is an acceptable alternative to the swatch square. Planner decides which to implement — both are within spec.

### 3. Create/Edit Modal

Structure: fixed-position full-screen overlay with centered panel.

```
overlay:  position: 'fixed', inset: 0, backgroundColor: 'rgba(0,0,0,0.4)', display: 'flex', alignItems: 'center', justifyContent: 'center', zIndex: 1000
panel:    backgroundColor: '#fff', borderRadius: '8px', padding: '1.5rem', minWidth: '320px', maxWidth: '480px', width: '90%'
```

Modal fields:
- Name input: same style as AuthPage — `width: '100%', padding: '0.5rem'`
- Color picker grid: 12 swatches in a row-wrap grid, each 32×32px clickable square with `borderRadius: '4px'`, selected state adds `outline: '3px solid #000', outlineOffset: '2px'`
- Icon picker grid: 15 icons in a row-wrap grid, each 40×40px clickable cell with centered Lucide icon at `size={20}`, selected state adds `backgroundColor: '#e5e5e5', borderRadius: '4px'`
- Submit button: disabled + "Saving..." during API call (matches AuthPage loading pattern)
- Error message: `<p style={{ color: 'red', marginTop: '0.75rem' }} role="alert">` (matches AuthPage exactly)
- Cancel button: plain text button, no special styling

### 4. Delete Inline Confirm (D-09 pattern)

State machine on each card:
1. **Idle:** trash icon button visible
2. **Confirming:** "Confirm delete?" text + "Yes, delete" button (red) + "Cancel" button
3. **Error:** error message string displayed inline below the card actions in red, card stays visible
4. **Deleted:** card removed from grid (optimistic or on API success)

No modal for delete. No toast. Inline only.

## Interaction States

### Loading States

| Context | Behavior |
|---------|----------|
| Page initial load | "Loading categories..." text replaces grid |
| Modal form submit | Submit button disabled, label → "Saving..." |
| Delete in progress | "Yes, delete" button disabled during API call |

### Error States

| Context | Display | Placement |
|---------|---------|-----------|
| Page load failure | Red `<p role="alert">` | Below h1 heading |
| Modal form API error | Red `<p role="alert">` | Below submit button (AuthPage pattern) |
| Delete blocked (422) | Red `<p role="alert">` | Inline on card, below action buttons |
| Delete network error | Red `<p role="alert">` | Inline on card |

### Accessibility

- All icon-only buttons: `aria-label` required (e.g., `aria-label="Edit category"`, `aria-label="Delete category"`)
- Modal: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` pointing to modal title id
- Error paragraphs: `role="alert"` (matches AuthPage)
- Color swatch buttons: `aria-label="Select color {hex}"` (e.g., `aria-label="Select color #FF6B6B"`)
- Icon picker buttons: `aria-label="Select icon {name}"` (e.g., `aria-label="Select icon utensils"`)
- Selected swatch/icon: `aria-pressed="true"`
