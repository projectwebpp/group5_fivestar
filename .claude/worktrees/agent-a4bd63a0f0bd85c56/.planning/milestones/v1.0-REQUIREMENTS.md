# Requirements Archive: v1.0 MVP

**Archived:** 2026-05-11
**Milestone:** v1.0 — Expense Tracker MVP

## v1 Requirements — All Complete

### Authentication
- [x] **AUTH-01**: User can register with email and password — ✓ v1.0
- [x] **AUTH-02**: User can log in and receive a JWT token — ✓ v1.0
- [x] **AUTH-03**: User can log out (token invalidated) — ✓ v1.0
- [x] **AUTH-04**: All expense/category/report endpoints require valid JWT — ✓ v1.0

### Expenses
- [x] **EXP-01**: User can add an expense (amount, currency, category, description, date) — ✓ v1.0
- [x] **EXP-02**: User can view all expenses with pagination (page, limit) — ✓ v1.0
- [x] **EXP-03**: User can filter expenses by date range, category, and amount range — ✓ v1.0
- [x] **EXP-04**: User can view a single expense's detail — ✓ v1.0
- [x] **EXP-05**: User can edit an expense (full PUT and partial PATCH) — ✓ v1.0
- [x] **EXP-06**: User can delete an expense — ✓ v1.0

### Categories
- [x] **CAT-01**: System provides predefined default categories — ✓ v1.0
- [x] **CAT-02**: User can create a custom category (name, icon, color) — ✓ v1.0
- [x] **CAT-03**: User can edit a category — ✓ v1.0
- [x] **CAT-04**: User can delete a category (blocked if active expenses reference it) — ✓ v1.0
- [x] **CAT-05**: User can view all categories — ✓ v1.0

### Analytics & Reports
- [x] **REP-01**: User can view monthly total expense summary (total + by category) — ✓ v1.0
- [x] **REP-02**: User can view expense breakdown by category (pie chart data) — ✓ v1.0
- [x] **REP-03**: User can filter expenses by custom date range for trend view — ✓ v1.0
- [x] **REP-04**: User can view daily and monthly average expense calculations — ✓ v1.0
